# Sorry cards

Sorry! - one of the best board games of all times.

This project was created due to a tired, well played deck of Sorry cards and shuffling lazyness!

It is a digital representation of a standard deck of cards, easy to click through on your phone.

## Features

- **Color Selection**: Choose your starting player color (red, blue, yellow, green)
- **Smart Turn Management**: Automatically cycles through players, with "2 Start, roll again" cards keeping the same player active
- **Complete Card Deck**: All standard Sorry! cards including movement cards and special "Sorry!" cards
- **Auto-shuffle**: Deck automatically reshuffles when empty
- **Mobile Friendly**: Optimized for phone use during gameplay

## Development

This project uses Vite for modern development and building.

### Setup

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Starts a local development server with hot reload at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

Builds optimized files to the `dist/` folder for deployment.

### Preview Production Build

```bash
npm run preview
```

## Project Structure

- `src/` - Source files for development
  - `index.html` - Main HTML structure
  - `script.js` - Game logic and card handling
  - `style.css` - Styling and layout
- `dist/` - Built files for production (generated by Vite)
